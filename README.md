# Srdjan Kojic (Srđan Kojić)

Agentic AI engineering lead in Berlin. I build multi-agent systems, the integrations that connect them to real systems and data, and the deterministic checks that stop them making things up.

## What I work on

- **Agent platforms.** For the last two years I've designed the agent infrastructure that client teams at Merck KGaA and Celonis use daily: a library of specialised agents, an orchestration layer with strict invocation rules, and PASS/FAIL validation gates. On the Merck workstream it ran on, delivery time fell 60–70%. At Celonis I built the AI code-review pipeline that runs with SonarQube and GitHub Actions ahead of human review.
- **Integrations.** Agent pipelines wired to Jira, Figma, Confluence, Chrome DevTools and Adobe Document Authoring through the Model Context Protocol. At AutoSync, Norway's largest toll-billing provider and a bank-owned financial-services company, I lead the multi-agent orchestration across company processes, which cut time-to-information by more than 40%.
- **Process automation and data pipelines.** Designed and built seven production automation processes in UiPath at AutoSync. They pull vehicle and address data from Norway's national registry into toll processing, invoicing and debt collection, and deliver the results as data feeds into Microsoft Dynamics.
- **Backend and databases.** Built Senor's Kjapp parking app end to end on Node.js and MongoDB. More recently, a Next.js and PostgreSQL service with database-backed sessions, service-layer authorization and streamed uploads ([secure-file-vault](https://github.com/skojic/secure-file-vault)).
- **Platform roots.** Ten years running infrastructure for Serbia's national pension fund: 3,000+ workstations, 40+ servers and the disaster recovery plan behind them. Since 2019, enterprise platforms in JavaScript and TypeScript at Cognizant Netcentric.

## Selected work

- **[aem-eds-figma-to-code](https://github.com/skojic/aem-eds-figma-to-code)**: an agentic pipeline from design to spec, build and a browser-checked PASS/FAIL verdict, built from three explicit-invocation skills and one config file. [Case study](https://skojic.vercel.app/work/figma-to-code)
- **[n8n-cv-fit-gate](https://github.com/skojic/n8n-cv-fit-gate)**: an n8n workflow that puts LLM extraction behind a deterministic gate. It fails loudly and names the missing field instead of inventing one.
- **[linkedin-scheduler-mcp](https://github.com/skojic/linkedin-scheduler-mcp)**: an MCP server that lets an AI assistant publish and schedule LinkedIn posts. Posts go out from GitHub Actions, so your computer can be off.
- **[secure-file-vault](https://github.com/skojic/secure-file-vault)**: a secure file upload service in Next.js, TypeScript and PostgreSQL, built by an AI agent through human-approved plans and pass/fail gates.
