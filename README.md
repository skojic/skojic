# Srdjan Kojic (Srđan Kojić)

Engineering lead in Berlin. I build AI agents, the integrations that connect them to real systems, and the checks that stop them making things up.

For the last two years I've designed the multi-agent systems that now write production code alongside client teams at Merck KGaA and Celonis, connected to Jira, Figma, Confluence and the browser through MCP. On the Merck frontend workstream, delivery time fell 60–70%. Before that: eight years of enterprise frontend work in JavaScript and TypeScript at Cognizant Netcentric, and ten years running infrastructure for Serbia's national pension fund.

## Selected work

- **[aem-eds-figma-to-code](https://github.com/skojic/aem-eds-figma-to-code)**: a skill pack that turns Figma designs into production code, then checks the result in a real browser before it passes. [Case study](https://skojic.vercel.app/work/figma-to-code)
- **[n8n-cv-fit-gate](https://github.com/skojic/n8n-cv-fit-gate)**: an n8n workflow that puts LLM extraction behind a deterministic gate. It fails loudly and names the missing field instead of inventing one.
- **[secure-file-vault](https://github.com/skojic/secure-file-vault)**: a secure file upload feature in Next.js, TypeScript and PostgreSQL, built by an AI agent through human-approved plans and pass/fail gates.
- **[linkedin-scheduler-mcp](https://github.com/skojic/linkedin-scheduler-mcp)**: an MCP server that lets an AI assistant publish and schedule LinkedIn posts. Posts go out from GitHub Actions, so your computer can be off.
